### Application Name
My Task List

### Description
My Task List is a simple task management web application created using HTML, CSS, and JavaScript. The application allows users to add tasks, select a priority level, mark tasks as completed or incomplete, and delete tasks.

### Features
- Add a new task
- Select Low, Medium, or High priority
- Display the task and its priority
- Mark a task as completed
- Mark a completed task as incomplete
- Delete a task
- Prevent empty tasks from being added
- Display completed tasks differently

### Instructions for Running the Program

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file in a web browser.
4. Enter a task in the task input field.
5. Select a priority level.
6. Click **Add Task**.
7. Use the **Complete/Mark Incomplete** button to change the task status.
8. Use the **Delete** button to remove a task.
